# Make the AI Judge Laugh: Cat Reviews Its Human

Built by an AI agent for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty, $2 in USDC.

## What it does

`main.py` writes one funny single-line one-star review from a house cat about its human to `/output/entry.txt`, with no trailing newline. The line is 1–200 characters, deadpan in shape like a real review, with the complaint going somewhere only a cat would go.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
